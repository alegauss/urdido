# The declaration

Generated by `urdido check --reference` from the schema in
`src/urdido/declaration.py`; do not edit it by hand.

A video is one `video.toml`. `urdido check <video.toml>` refuses a key no
table takes, with the nearest valid name, and `urdido build` runs the same
check first.
`urdido check --schema` prints the JSON Schema an editor can complete from.

## Source kinds

- `chaptered` needs `folder`, `recording`, `chapters`
- `scenes` needs `listing`
- `illustrated` needs `declaration`
- `explainer` needs `shots`

## Shorts cutters

`[shorts]` declares one of two cutters, never both:

- the scenes selection, cut by `urdido build --cut short:<c>`: `declaration` and nothing else;
- `urdido shorts`: every other key in the table below.

## [video]

The video's name, its languages and, for a variant, its base.

- `name` (required): a string
- `languages` (required): *any name*
- `folders`: *any name*
- `title_languages`
- `revision`: a string
- `base`: a string
- `frame`: a array, [1920, 1080] if absent

## [roots]

Folders a `<name>` path starts at, by relative path or `$VAR`.

Any key, each a name of your own.

## [output]

Where the build writes: `folder` (`video`) and `parts` inside it.

- `folder`: a string, "video" if absent
- `parts`: a string, "parts" if absent

## [source]

What the video is made of: its `kind` and what that kind reads.

- `kind` (required): a string
- `declaration`: a string
- `listing`: a string
- `folder`: a string
- `vertical_folder`
- `recording`: a string
- `chapters`: a number
- `newer_than`: a array
- `record_command`
- `vertical_record_command`
- `shots`: a string
- `footage`: a string, "footage" if absent
- `lead`: a number, 0.4 if absent
- `gap`: a number, 0.5 if absent
- `end`: a number, 4.5 if absent
- `styles`: a string
- `closing`: *any name*
- `fonts`: a string
- `sources`: a string

## [narration]

The script, the folder of bought takes, and an optional tempo.

- `script` (required): a string
- `takes` (required): a string
- `tempo`: a number, 1.0 if absent

## [cards]

The cards' declaration (theme and words), and a browser channel.

- `declaration`: a string
- `words`
- `channel`: a string

## [music]

The bed under the narration and how far it ducks.

- `bed`: a string
- `reference`: a number, -18.0 if absent
- `between`: a number, 0.4 if absent
- `under`: a number
- `ramp`: a number, 0.4 if absent

## [audio]

Loudness target, true-peak ceiling and their margin.

- `target`: a number, -14.0 if absent
- `peak`: a number, -1.0 if absent
- `tolerance`: a number, 0.3 if absent
- `margin`: a number, 1.5 if absent

## [opening]

A chaptered video's opening: animation, footage, photos, site screens.

- `intro`
- `intro_meta`
- `footage`
- `photos`
- `store`
- `screens`: `path`, `scroll`, `follow`

## [cuts]

Which extra cuts a chaptered build makes.

- `teaser`: a boolean, false if absent

## [captions]

Translated captions, burned-in captions and the player's safe area.

- `translations`: *any name*
- `burn`
- `safe_area`: `bottom`, `action`

## [highlights]

Word-timed callouts over the picture, and their fonts.

- `declaration`: a string
- `fonts`: a string

## [claims]

The narration's claims, their evidence and how strictly they are held.

- `declaration`: a string
- `action`: a string, "warn" if absent

## [description]

The YouTube description: summary, notes, sources, licence, words.

- `summary`
- `notes`
- `sources`
- `generated`
- `strings`
- `license_label`
- `license_url`
- `changes`

## [text_checks]

Encoding, glyph and layout checks over the text a video draws.

- `action`: a string
- `protected_tokens`
- `glyphs`: a boolean

## [mark]

A brand mark in a corner through the whole video.

- `logo`: a string
- `corner`: a string, "top-left" if absent
- `margin`: a array, [70, 50] if absent
- `size`: a number, 44 if absent
- `opacity`: a number, 0.9 if absent
- `font`: a string
- `background`: a string
- `text`: a string

## [anchors]

Named moments a scene can be timed against.

Any key, each a name of your own.

## [qa]

How the final verification treats a flash.

- `flashes`: a string, "error" if absent
- `flash_threshold`: a number, 6.0 if absent
- `flash_refuse`: a number, 40.0 if absent

## [publish]

Where the transcript and stills are published.

- `declaration`

## [resolve]

The DaVinci Resolve project's settings.

- `declaration`

## [thumbnail]

The thumbnail: layout, pictures, words, published title, pair check.

- `layout`: a string
- `out`: a string
- `picture`: `file` (required), `at`, `box`, `reason`, `license`, `author`, `url`, `fit`, `margin`, `background`
- `proof`: `file` (required), `at`, `box`, `reason`, `license`, `author`, `url`, `fit`, `margin`, `background`
- `words`: *any name*
- `title`: *any name*
- `check`: `stopwords`, `superlatives`, `drawn`

## [shorts]

YouTube Shorts: the scenes selection, or `urdido shorts` cuts.

- `declaration`
- `plan`
- `picture`
- `mix`
- `words`
- `out`
- `link`
- `tags`
- `sources`
- `credit`
- `fixes`
- `notes`: *any name*
- `look`: `night`, `accent`, `ink`, `title_font`, `text_font`, `fonts`
- `rules`
- `pointer`: *any name*
- `cut`: `n`, `takes`, `hook`, `title`, `text`

## [record]

The steps `urdido record` runs to record a scene video.

- `step`: `name` (required), `command` (required), `makes`, `always`

## [terminal]

A terminal scene's commands, run for real by `urdido terminal`.

- `work`: a string
- `session`: a string
- `shell`: a string
- `title`: a string
- `keep`: *any name*
- `scenes`: *any name*

## [instances]

Product instances a recording runs against, by name.

Any key, each a name of your own.
