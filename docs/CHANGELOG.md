- ✅ **UR16** **There is no urdido package to install: no pyproject, source tree, console script or version** — urdido installs with pip install -e .[test], answers urdido --version, and refuses a missing extra (cards, narration, polyweave) by naming its pip install (design recorded in `README.md`).

- ✅ **UR18** **Nothing checks a push: no CI runs ruff and pytest on Linux and Windows** — gates.yml runs ruff and tools/gate.py on Ubuntu and Windows with Python 3.12 and 3.13, naming each skip, though no push has run it yet (design recorded in `.github/workflows/gates.yml`).
- ✅ **UR19 (release tooling)** **A version cannot reach PyPI except by a hand-run upload with a token** — publish.yml takes a v* tag through build, twine check, a tag-versus-package check and a wheel install to TestPyPI, PyPI and a GitHub release, and tools/release.py tags it.
- ✅ **UR20 (CLAUDE.md and friction skill)** **An agent working in this repo or driving urdido has no CLAUDE.md, skill or friction path** — CLAUDE.md gives the gates, commits and code rules, and the urdido-friction skill, installed globally, files from a consumer through roadkeep -C with (from:).

## Block B — The engine extracted (videomaker without marketing)

- ✅ **UR21** **urdido holds none of the videomaker code, and marketing's history of each module would be lost by a copy** — video-maker's 75 commits merged into src/urdido, tests and js under the urdido name; the suite passes here and skips by name without marketing (design recorded in `tests/marketing.py`).
- ✅ **UR22** **The build defaults its roots to sibling Turing and Shio checkouts and writes to a fixed video/ folder** — A declaration names its roots in [roots] and its output in [output]; no module holds a sibling path, and a path at an undeclared root is refused (design recorded in `docs/video-maker.md`).
- ✅ **UR23** **A misspelled or missing key in video.toml fails as a KeyError deep inside the build** — urdido check and every build refuse an unknown video.toml key with its file, table and nearest name, and a missing one; check --schema prints JSON Schema (design recorded in `docs/video-maker.md`).
- ✅ **UR24** **Library code raises SystemExit and the CLI is an if-chain, so urdido can be neither embedded nor discovered** — urdido --help lists every command; the library raises UrdidoError with a remedy, which only the command line turns into an exit (design recorded in `docs/video-maker.md`).
- ✅ **UR25** **Polyweave is called through three separate subprocess wrappers, and its polyweave.toml is read directly** — One adapter runs polyweave, parses its answers and reads its config; the rest calls urdido.providers, and tests answer through a fake RUN (design recorded in `docs/video-maker.md`).
- ✅ **UR26** **Word times come from a direct ElevenLabs Scribe call inside the package, with no provider seam** — Word times come through a transcriber seam, Scribe being one provider and a test a fake, in the language the declaration gives; the language default is gone (design recorded in `docs/video-maker.md`).
- ✅ **UR27** **Description, chapter and credit texts are hardcoded in Portuguese, and the description is shaped only for YouTube** — Description words follow the build language's table, overridable by [description.strings]; YouTube's limit and links live in a target (design recorded in `docs/video-maker.md`).
- ✅ **UR28** **The Turing WordPress demo's store scraper, stills and transcript publishing live inside the core build** — The opening's site screens are declared as paths and follow selectors, publishing writes only where publish.json says, and no module names a shop (design recorded in `docs/video-maker.md`).
